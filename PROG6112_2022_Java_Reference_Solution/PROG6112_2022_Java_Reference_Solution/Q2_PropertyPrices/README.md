# Question 2 – Average Property Prices

Console Java application using a 2D array for the three property prices (Flat,
Townhouse and House) in Gauteng, Natal and Cape. It prints each province and
its total average property price.

## Run
Run `za.co.prog6112.q2.PropertyPriceReport` from the IDE or Maven project.
JUnit 5 tests are included for each province total.
