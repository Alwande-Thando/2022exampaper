# Question 3 – Travel Information

Java Swing GUI with start/end location combo boxes (Cape Town, Durban, Port Elizabeth)
and a travel type combo box (Airplane, Train). Submit validates that the two locations
are different, appends the journey to `travel.txt`, and displays it in the list.
Existing lines in `travel.txt` are loaded into the list when the application starts.

## Run
Open this folder as a Maven project and run `za.co.prog6112.q3.TravelFrame`.
The `travel.txt` file is created in the application's working directory when the
first valid journey is submitted.
