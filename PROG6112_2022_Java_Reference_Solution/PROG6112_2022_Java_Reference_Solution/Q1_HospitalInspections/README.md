# Question 1 – Hospital Inspections

Java Swing solution for capturing up to five hospital inspection records.
Each record stores the hospital name, location and years since the last inspection (1–5).

## Run
Open this folder as a Maven project in IntelliJ IDEA or NetBeans. Run
`za.co.prog6112.q1.HospitalInspectionFrame`.

The **Tools** menu repeats the Save, Print and Clear button actions. The **File > Exit**
menu item closes the application.
