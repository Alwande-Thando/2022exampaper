# PROG6112 2022 – Java Reference Solutions

This ZIP contains three separate Maven projects matching the three questions in the
uploaded 2022 Programming 1B take-home exam:

1. **Q1_HospitalInspections** – Swing GUI; captures up to five hospital inspections,
   prints records to a list and provides File > Exit and Tools > Save/Print/Clear.
2. **Q2_PropertyPrices** – 2D array of the supplied average prices for Gauteng, Natal
   and Cape; prints the total for each province.
3. **Q3_TravelInformation** – Swing GUI; validates start/end locations, appends to
   `travel.txt`, and loads saved travel rows into a list.

## Notes
- Java 17 and Maven are configured in each project.
- Q2 includes JUnit 5 tests for the three province totals.
- The exam does not explicitly request JUnit tests; the main focus is matching the
  stated GUI, array, validation and file-handling requirements.
- Open each question folder separately in IntelliJ IDEA or NetBeans as a Maven project.
- These are reference implementations for study. Review the code and make sure you
  understand each class, method, event handler and array/file operation.
